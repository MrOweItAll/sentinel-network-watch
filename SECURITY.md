# Security and privacy

Keep credentials and household data outside this source repository, including in
private forks. Topics used as ntfy access capabilities, bearer tokens, SSH private
keys, passwords, captures, host bindings and review decisions are runtime data.
Use `init-case` for an explicitly protected review folder and keep root Linux
configuration at mode 0600. A sync client running as you can still read your files.

An unfamiliar endpoint needs investigation. A port number, signature, TLS session,
or device name does not prove that traffic is authorized. Approval records are
review decisions and do not change a firewall. This release cannot observe all
household traffic or certify that an encrypted stream is wanted.

Use current Python/security updates and review changes before running installers
as root. The installer preserves configuration and data, leaves timers disabled,
and does not install Docker, change household DNS, change router settings, or
alter SSH/firewall access. Follow the recovery guide for an existing installation.

Do not put a vulnerability report containing credentials or household evidence in
a public issue. Use GitHub private vulnerability reporting if enabled; otherwise
request a private reporting channel without including the sensitive details.
